# 🐉 龙没有耳朵 · 3D无限跑酷

一个基于 **Three.js + WebGL** 开发的纯网页3D跑酷小游戏。

无需安装客户端，打开浏览器即可游玩。

---

## 🎮 游戏介绍

玩家控制角色不断向前奔跑：

- 躲避障碍物
- 收集金币
- 挑战更远距离
- 创造最高分

支持电脑和手机浏览器。

---

## ✨ 当前功能

✅ Three.js 3D场景

✅ 无限道路生成

✅ 第三人称摄像机

✅ 自动奔跑系统

✅ 左右移动

✅ 跳跃系统

✅ 障碍物随机生成

✅ 金币收集

✅ 距离统计

✅ 游戏失败重启

✅ 手机触屏按钮控制


---

## 🎮 操作方式

### 电脑

|操作|按键|
|-|-|
|向左移动|← / A|
|向右移动|→ / D|
|跳跃|空格 / ↑|


### 手机

使用屏幕下方按钮：

⬅ 左移

⬆ 跳跃

➡ 右移
